## 簡介

PMIX 是一個預測市場指數項目，提供兩類核心指數：

| 指數 | 全稱 | 衡量 |
| :--- | :--- | :--- |
| **PMCI** | Prediction Market Consensus Index | 事件發生的整體預期方向 |
| **PMVIX** | Prediction Market Volatility Index | 市場信念分歧程度 |

兩者共同構成預測市場的完整狀態描述。

---

## 指數家族

### PMCI（共識指數）

將預測市場上多元合約的即時價格進行加權平均，反映市場對「事件發生可能性」的整體判斷。

**版本**：標準版、宏觀、政治、經濟、地緣、科技、氣候、加密、等權重、Polymarket、Kalshi

### PMVIX（波動率指數）

將預測市場上多元合約的「信念分歧程度」加權壓縮為連續數字，反映市場的集體不確定性。

**版本**：標準版、宏觀、政治、經濟、地緣、科技、氣候、加密、等權重、Polymarket、Kalshi、交易日年化、月度年化、週度年化、基點尺度

## 核心公式

### PMCI

$$
\text{PMCI} = \frac{\sum_i w_i \cdot q_i}{\sum_i w_i}
$$

### PMVIX

$$
\text{PMVIX} = \sqrt{365 \times \frac{\sum_i w_i \cdot q_i(1-q_i)}{\sum_i w_i}} \times 10.47
$$

### 權重方法（標準版）

$$
w_i = \sqrt{\text{Depth}_i \times \text{Volume}_{24h,i}}
$$

## 指數解讀

### PMCI

| 數值 | 市場狀態 |
| :--- | :--- |
| 0–20 | 極不可能發生 |
| 20–40 | 不太可能發生 |
| 40–60 | 無明顯傾向 |
| 60–80 | 可能發生 |
| 80–100 | 極可能發生 |

### PMVIX

| 數值 | 市場狀態 |
| :--- | :--- |
| 0–20 | 自信且共識強烈 |
| 20–40 | 正常不確定性 |
| 40–60 | 不確定性升高 |
| 60–80 | 高度不確定性 |
| 80–100 | 極端不確定性 |
